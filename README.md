# Análisis de clientes de ConectaTel

## Descripción del proyecto

Este proyecto forma parte de mi formación como Analista de Datos en TripleTen.

El objetivo es explorar los datos de clientes de ConectaTel, una empresa de telecomunicaciones, para identificar patrones de uso, analizar diferencias entre planes y conocer mejor los segmentos de clientes.

## Herramientas utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Etapas del análisis

1. Exploración inicial del conjunto de datos.
2. Revisión de la calidad de los datos.
3. Análisis de variables numéricas mediante estadísticas descriptivas.
4. Visualización de distribuciones y detección de valores atípicos.
5. Comparación de patrones de uso entre los planes Básico y Premium.
6. Segmentación de clientes por edad y nivel de uso.
7. Elaboración de conclusiones y recomendaciones de negocio.

## Principales hallazgos

- Se identificaron diferencias en la distribución de clientes según su nivel de uso.
- El grupo de uso medio concentra una parte importante de los clientes.
- Se observaron valores atípicos en llamadas, mensajes y minutos de llamada que requieren interpretación antes de decidir si deben excluirse.
- Se detectaron valores de edad no válidos que deben revisarse para evitar errores en la segmentación.

## Recomendaciones

Profundizar en el análisis de los segmentos de clientes, revisar los problemas de calidad de datos y estudiar el comportamiento de uso por plan para apoyar futuras decisiones comerciales.

## Cómo consultar el proyecto

Abre el archivo `.ipynb` incluido en este repositorio con Jupyter Notebook o JupyterLab para revisar el código, las visualizaciones y las conclusiones del análisis.

Para volver a ejecutar el análisis se necesita disponer del conjunto de datos original utilizado en el proyecto.
